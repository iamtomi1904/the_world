# Fallen Knight asset prompts

Built-in image_gen, transparent background. Reference: existing paladin foot/mounted atlas. Originals retained.



## foot

Use case: stylized-concept. Production sprite atlas for an existing medieval top-down pixel defense game. Transparent background, no text, no labels, no grid lines. Exactly square 6 columns x 6 rows equal cells, all 36 complete frames fit with 12% transparent padding in EVERY cell; feet baseline 88% down each cell, anchor consistent. Coarse readable pixel art, limited charcoal/steel/purple/green palette, no smooth painterly gradients. Three-quarter view facing RIGHT in every frame, flip at runtime for left. Row1 six idle breathing frames; row2 six walking frames; row3 six heavy sword attack frames anticipation,windup,swing,impact,followthrough,recovery; row4 six casting frames raise sword, channel, flare,recoil,recover; row5 six hurt/kneel frames; row6 six falling death frames. Stable identity and scale in all frames. Create the FALLEN KNIGHT, living human inside sealed heavy black steel plate, small bone spikes on shoulders/elbows/knees, narrow purple visor, cracked old holy chest emblem with subtle poison-green cracks, ragged black cape. Huge two-handed asymmetrically serrated dark greatsword, small skull at hilt not a monster blade, subtle purple-green edge glow. Broad silhouette related to reference paladin but dark and menacing. Keep body size same across rows. Reference is style/armor lineage only, remove ALL gold/white holy motifs.

## icons

Each icon centered within 12% padding, no labels, no letters or borders. Palette charcoal steel purple with restrained green and dark red accents.
